## 1. 「どんな商品でもこのOSで運営可能か？」に対する結論と設計

### 結論：完全に運営可能です。
システム構築、顧問サービス、アフィリエイト、デジタル商材、メディア運営など、**どのようなビジネスモデルであっても、破綻せずにAIと共創・運営できる「商品タイプ駆動型（Archetype-Driven）アーキテクチャ」**を採用します。

### ビジネスモデル別の管理要件と本OSの対応力

| ビジネスモデル | 主な管理項目（商品開発〜運用） | 本OSでの管理方法（マトリクス＆リスト） | AI社長・専門AIとの協働例 |
| :--- | :--- | :--- | :--- |
| **システム構築**（受託・制作） | 仕様書、マイルストーン、納期、検収、個別契約、着手金/残金請求 | ・タスクカンバン（要件定義→実装→検収）<br>・契約書（受託契約・NDA）<br>・請求書（分割請求対応） | 画面要件の整理、WBS（タスク分解）自動生成、仕様書ドラフト作成 |
| **顧問サービス**（コンサル・サポート） | 月次MTG議事録、アドバイス履歴、KPI診断、定額定期請求 | ・診断管理（既存MSTの企業カルテ）<br>・定期請求管理（サブスク/月次）<br>・顧問契約書（自動更新） | 経営課題分析、月次レポートの下書き作成、次回提案事項の壁打ち |
| **デジタル商材**（教材・テンプレ・SaaS） | コンテンツアセット、販売LP、配布URL、バージョン履歴、プラットフォーム売上 | ・コンテンツ管理リスト<br>・プロモーションツールリスト<br>・売上・決済履歴リスト | カリキュラム構成案、セールスレター作成、FAQ・サポートマニュアル作成 |
| **アフィリエイト** | 提携ASP、対象案件、記事/LP URL、提携リンク、成約数、確定報酬 | ・案件管理リスト<br>・記事制作スケジュール（カレンダー）<br>・ASP別入金管理 | 検索意図の分析、比較記事構成作成、訴求文（マイクロコピー）生成 |
| **メディア運営**（ブログ・SNS・動画） | 企画ネタ帳、執筆スケジュール、外注ライター管理、PV/収益KPI | ・コンテンツ制作パイプライン<br>・外注委託契約＆請求書受領<br>・月次アナリティクス集約 | 記事タイトル・目次出し、SEOキーワード分析、SNS投稿文の自動量産 |

## 2. どんな商品も扱える「汎用商品エンジン」の設計

### ① 商品タイプ（Product Archetypes）
商品を登録する際、以下のプリセットタイプを選択可能にします（各タイプに応じた入力項目・テンプレートが自動展開されます）：
1. **プロジェクト型（受託・システム開発・制作）**: 納期、マイルストーン、検収日、工数
2. **リテーナー型（顧問・月額コンサル・保守）**: 契約期間、月額費用、定期MTGサイクル、レポート対象
3. **デジタル資産型（コンテンツ・教材・ツール）**: ダウンロード先、販売プラットフォーム、バージョン、価格
4. **メディア・成果報酬型（オウンドメディア・アフィリエイト）**: 媒体URL、提携ASP、ターゲットキーワード、想定PV
5. **汎用カスタム型**: ユーザー自身が自由に項目を定義可能

### ② 動的カスタムフィールド＆リスト管理
- 商品ごと、またはカテゴリーごとに「独自の列・属性（例: ASP名、検収日、Google Driveリンク、Githubリポジトリ）」をノーコードで追加できる柔軟なデータ構造を持たせます。

### ③ 「AI社長」との商品開発共創ワークフロー（5ステップ）
このOS上でAIと一緒に新しい商品をゼロから開発し、リリース〜運用まで持っていく一貫したフローを提供します：

```
[Step 1: アイデア・市場分析] ── AI社長「シドウ」やリサーチAIと壁打ち、ターゲット・競合・ポジショニング策定
         │
[Step 2: 商品設計・要件定義] ── カリキュラム、仕様書、提供サービス内容をAIが自動骨子化
         │
[Step 3: マーケティング準備] ── LP構成、キャッチコピー、営業資料、販売スケジュールを生成しタスク化
         │
[Step 4: 契約・決済整備]   ── 契約書テンプレート選択、請求サイクル設定
         │
[Step 5: プロダクトハブ開設] ── 商品としてOSに登録され、開発・マーケ・顧客・売上が一元管理開始
```

## 5. 実装フェーズと進め方

1. **Phase 1: 統合基盤とナビゲーションの構築**
   - 既存MST業務OSとMyAI Studioの型・UIテーマ（Tailwind Dark Slate）を統合。
   - `UnifiedNavbar` と常駐型 `QuickPresidentDrawer` を実装。
2. **Phase 2: AI社長（MyAI Studio）機能の組み込み**
   - AI社長「シドウ」、プロジェクト、タスク（カンバン）、承認、専門AIプリセット、トークン計算を統合。
3. **Phase 3: 汎用商品タイプ・マトリクス・リスト管理エンジンの実装**
   - 商品タイプ別テンプレート（システム受託、顧問、デジタル商材、アフィリエイト、メディア）。
   - 「カテゴリー表示」と「商品別表示」の双方向マトリクスビュー。
   - カスタムリスト＆リストカテゴリー（契約・請求・ツール・タスク・リード）の動的管理。
4. **Phase 4: AI商品共創ウィザード＆非AI業務自動化の実装**
   - AI社長と一緒に新商品を企画・要件定義・タスク分解できる対話型ウィザード。
   - ステータス変更時の自動タスク生成やリマインドなどのルールベース自動化。
5. **Phase 5: ビルド確認・動作検証**
   - TypeScript型検査、Viteビルド、各画面の動作確認。
