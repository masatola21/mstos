# 文書・帳票自動流し込みシステム (Document & Template Auto-Population Hub)

契約書、提案書、請求書、診断レポートなどのHTMLおよびドキュメントひな形に、構造化されたデータをAIを介さず「確実かつ自動的に流し込む」ためのプロフェッショナル向けWebアプリケーションの実装計画です。

## ユーザーレビューと重要な決定事項

> [!IMPORTANT]
> - **決定論的テンプレートエンジン**: AIによる生成やハルシネーション（幻覚）を一切排除し、`{{variable_name}}`形式のプレースホルダー置換による100%正確な自動流し込み。
> - **標準4大ひな形を搭載**: 「契約書」「提案書」「請求書」「診断レポート」のデフォルトHTMLテンプレートをプリセット。独自のひな形追加・編集も可能。
> - **エクスポートと印刷**: ワンクリックでのPDF印刷、HTMLファイルダウンロード、クリップボードコピーに対応。

- **確認済み決定事項**: ユーザーが事前に用意・登録したHTML/文書ひな形に対して、フォーム入力データを確実にマージする仕組み。
- **追加の要望・調整**: CSVやJSON一括インポート機能の有無（デフォルトでサンプルデータ一括反映とカスタム編集に対応）。

---

## 1. 概要とコアコンセプト

- **何をするものか**: 契約書、提案書、請求書、診断レポートのHTMLひな形を管理し、クライアント情報や金額、診断スコア等のデータをすばやく流し込んでプレビュー・印刷・出力できる専用ハブ。
- **ターゲットユーザー**: フリーランス、中小企業経営者、コンサルタント、事務管理部門など、正確な書類作成を効率化したいユーザー。
- **主なメリット**: 手作業によるコピペミスの防止、公式テンプレート通りの100%正確な出力、即座のPDF印刷・データ保存。

---

## 2. ユーザー体験とビジュアルデザイン

- **主要なユーザーフロー**:
  1. **ダッシュボード**: 登録済みテンプレート一覧、最近生成した書類の履歴、クイック作成ボタン。
  2. **テンプレート管理・編集**: 4つの標準テンプレートの閲覧・編集、変数 (`{{client_name}}` など) のカスタマイズ。
  3. **データ入力フォーム**: 顧客名、案件名、明細、金額、診断結果などの入力・プリセット選択。
  4. **リアルタイムプレビュー & 出力**: 流し込み結果のライブプレビュー、PDF印刷、HTMLダウンロード。
- **ビジュアルデザインとテーマ**:
  - *デザイン方向性*: クリーンで洗練されたミニマルSaaS（ダークスレートのアクセント、清潔感のある白背景、高精度のタイポグラフィ）。
  - *カラーパレット*: ニュートラルキャンバス（`#0F172A` / `#F8FAFC`）、境界線（`#E2E8F0`）、アクセントカラー（`#2563EB` ブルー）。
  - *フォント*: 見出し・本文に `Plus Jakarta Sans`（日本語対応フォント）、変数や数値には `JetBrains Mono`（等幅・等数数字対応）。
  - *コンポーネント*: フラットカード、極細のボーダー、構造化されたフォームグリッド。
- **インタラクティブフィードバック**: 入力時の即時反映、成功トースト通知、未入力時のわかりやすいガイド。

---

## 3. 主要な製品決定とトレードオフ

- **決定 1: LLM生成ではなく決定論的テンプレートエンジンを採用**
  - *アプローチ*: ハンドルバーズ形式（`{{変数名}}`）の正確な文字列置換。
  - *理由*: 法律・請求に関わる書類でハルシネーション（誤った金額や条文の勝手な生成）が絶対に起きないようにするため。
- **決定 2: クライアントサイド永続化（localStorage）**
  - *アプローチ*: Reactの状態管理と `localStorage` によるテンプレート・履歴保存。
  - *理由*: バックエンド構築の手間を省き、オフラインでもすぐ動作し、自分好みのひな形を保存できるようにするため。

## 4. 技術アーキテクチャとデータ戦略

```
┌────────────────────────────────────────────────────────┐
│                   アプリケーション状態                     │
│  (テンプレート一覧、データプリセット、生成履歴)               │
└───────────┬────────────────┬────────────────┬──────────┘
            │                │                │
            ▼                ▼                ▼
┌──────────────────┐ ┌───────────────┐ ┌─────────────────┐
│ テンプレート管理   │ │ データ入力フォーム│ │ リアルタイム合成 ＆ │
│ (HTML＋変数定義)  │ │ (顧客・明細等)  │ │ プレビューエンジン │
└───────────┬──────┘ └───────┬───────┘ └────────┬────────┘
            └────────────────┼────────────────┘
                             ▼
             ┌───────────────────────────────┐
             │   エクスポート / 印刷 (PDF)     │
             └───────────────────────────────┘
```

- **データモデル**:
  - `Template`: `{ id, title, type ('contract'|'proposal'|'invoice'|'report'), htmlContent, variables: string[] }`
  - `DocumentData`: `{ companyName, contactName, issueDate, dueDate, items: [{name, qty, unitPrice}], notes, customFields }`
  - `HistoryItem`: `{ id, templateId, title, clientName, createdAt, htmlOutput }`
- **主要な処理シーケンス**:
  1. テンプレート選択 -> 2. デフォルト変数・顧客データのロード -> 3. フォーム入力によるリアルタイム置換 -> 4. PDF印刷 / HTMLダウンロード。
