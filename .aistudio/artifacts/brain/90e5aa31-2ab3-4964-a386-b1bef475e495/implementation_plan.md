# 商談・顧客支援・タスク統合カレンダー 実装計画書

## 1. 概要
商談（初回ヒアリング・提案面談・フォロー期日）、顧客支援（定期面談・支援ミーティング・マイルストーン）、社内タスク納期、請求・入金期日、契約開始・更新日を横断的に集約し、一目でスケジュール把握とアクションができる統合カレンダーワークスペースを構築しました。
また、ワンクリックで個人の Google カレンダーに予定（タイトル・日時・対象企業・アジェンダ・Meet URL）を直接転送・登録できる連携機能を搭載しています。

## 2. 実装完了機能

### ① 多元ソースのリアルタイム集約
- **商談 (Deals)**: 商談日 (`meeting_date`)、次回フォロー期日 (`next_followup_at`)、提案プラン名、企業名、商談金額（税抜金額 + 消費税10% = 税込総額表記）。
- **反響リード (Leads)**: 初回面談予定日 (`meeting_date`)、開始時間 (`meeting_start_time`)、次回アクション期日 (`next_action_at`)。
- **顧客支援 (Customer Support)**: 支援案件の次回面談日時 (`next_meeting_at`)、支援テーマ、支援フェーズ、個別面談記録のアジェンダ・宿題。
- **請求・入金期日 (Invoices)**: 請求書の支払期日 (`dueDate`)、請求先、金額（税抜・消費税10%・税込表記）、ステータス（入金待ち/超過/完了）。
- **契約期間 (Contracts)**: 契約開始日 (`startDate`)、契約満了・更新期日 (`endDate`)。
- **社内タスク (Tasks)**: 業務タスク納期 (`dueDate`)、優先度（高/中/低）、担当者、進捗。
- **直接登録したスケジュール (Custom Appointments)**: カレンダー上から社内MTGや個別アポイントを自由に登録可能。

### ② 多彩な表示モード
- **月表示 (Month View)**: 日・月〜土の月間カレンダーグリッド。当日ハイライト、カテゴリ別カラーバッジ、セル内クイック追加ボタン。
- **週表示 (Week View)**: 直近7日間の日別カラム。面談の詰まり具合や空き時間を直感的に把握可能。
- **アジェンダ一覧表示 (Agenda View)**: 「期限超過/要対応」「本日」「明日」「今週」「来週以降」に自動分類した時系列リスト。

### ③ Google カレンダー 1-Click 即時連携
- 各予定の「Googleカレンダーに追加」ボタンをクリックすると、Google カレンダー作成画面が新規タブで起動。
- 面談タイトル、日時（終日または開始・終了時刻）、対象企業名、オンライン面談URL、アジェンダ・宿題メモが自動入力された状態で即時保存可能（OAuth認証不要・ストレスフリー）。

### ④ 該当台帳へのダイレクトジャンプ
- 各予定詳細モーダルまたはカードから、ワンクリックで該当企業の商談一覧、顧客支援ワークスペース、契約・請求書プレビュー画面へ直接移動。

### ⑤ 直感的なナビゲーション配置
- ナビゲーションバーの「反響・商談」グループおよび「顧客・支援」グループの双方に「予定カレンダー（商談・支援）」タブを配置。
- 営業ダッシュボードのメインバナーにも直接アクセスボタンを配置。
