# AIプロバイダー設定

AIチャットでは役割ごとに Gemini、Groq、OpenRouter の接続先とモデルIDを選べます。既定値は Gemini です。設定は「AIモデル設定」から選び、ログイン中のMSTワークスペースに保存されます。APIキー自体はSupabaseやブラウザーに保存しません。

## APIキー

アプリを動かすサーバー／デプロイ環境に、利用する提供元のキーを環境変数として登録してください。

- `GEMINI_API_KEY` — Google AI Studio / Gemini API
- `GROQ_API_KEY` — Groq API
- `OPENROUTER_API_KEY` — OpenRouter API

キーを設定していない提供元を選ぶと、チャットはAPIキー未設定のエラーを返します。キーを登録した後、サーバーを再起動または再デプロイしてください。

## 無料利用を優先するとき

- Geminiは現在の無料枠内で使う場合に選択します。
- Groqは提供アカウントの無料レート制限内で使います。
- OpenRouterでは `openrouter/free` または `:free` で終わるモデルIDのみ受け付けます。無料モデルの在庫と制限は変わることがあります。

MSTは上限超過時に別提供元へ自動切替しません。無料枠が尽きたときに意図せず有料利用へ進まないよう、設定画面から別の提供元へ手動で切り替えてください。トークン使用量はAPI応答に使用量が含まれる場合に記録されます。提供元によってはストリーミング時に使用量を返さず、「未取得」になることがあります。

モデルIDと無料枠は提供元側で変更されることがあります。デプロイ環境のAPIキー、利用上限、選んだモデルの現行条件を確認してください。
